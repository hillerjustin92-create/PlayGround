Setup

In drei Schritten
startklar.

Kein Framework, keine Datenbank. Nur Python, ein Telegram-Token und deine lokale OpenWebUI-Instanz.

bash · ki-kumpel
# 1. Token und Ziel setzen
export TELEGRAM_BOT_TOKEN="dein-token"
export OPENWEBUI_BASE_URL="http://127.0.0.1:8080"

# 2. Optional: API-Key und Modell festlegen
export OPENWEBUI_API_KEY="dein-key"
export OPENWEBUI_MODEL="llama3.2"

# 3. Bot starten
python3 kumpel.py

# Einmalig prüfen, ohne Telegram
python3 kumpel.py --check
